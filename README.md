# Axiora Labs - Premium Digital Agency Website

This is a modern, high-performance startup-level website for **Axiora Labs**, built with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- **Premium UI/UX**: Apple/Stripe inspired minimal and futuristic design.
- **Micro-interactions**: Smooth transitions and hover effects using Framer Motion.
- **Glassmorphism**: Elegant card components with backdrop blurs.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Dynamic Content**: Data-driven pages for Services, Portfolio, Blog, and Careers.
- **Zustand Store**: Efficient state management for global theme and menu states.

## Tech Stack
- **Frontend**: React 19 + Vite
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion (motion/react)
- **Icons**: Lucide React
- **Routing**: React Router DOM 7
- **State**: Zustand
- **SEO**: React Helmet Async

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## Deployment

### Vercel / Netlify
1. Connect your GitHub repository.
2. Set the build command to `npm run build`.
3. Set the output directory to `dist`.
4. Deploy!
